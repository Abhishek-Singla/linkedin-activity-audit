# Report template

Use this structure. Keep it factual. Mark each row Confirmed (seen on the page) or Inferred.

```
# LinkedIn activity audit - <account name> - <date>

Chrome profile used: <profile label / account email>
Pages read: <list>

## Summary
- Pending sent invitations: <N> (<n> with a note, <n> without)
- Connections: <total>; accepted in the last 30 days: <n>
- Messages you sent (visible threads): <n>
- Published posts: <n>   Published articles: <n>
- Drafts: <n>   Scheduled posts/articles: <n>

## Pending invitations
| Person | Headline | Sent (approx.) | Note? |
|---|---|---|---|

## Recent connections
| Person | Connected on |
|---|---|

## Sent messages / threads
| Person | Date | Last line |
|---|---|---|

## Posts, articles, drafts, scheduled
| Item | Type | Status | Date |
|---|---|---|---|

## Timeline
| When (approx.) | Activity | Evidence | Confidence |
|---|---|---|---|

## Not checked / gaps
- <anything the browser could not see: older history, other devices, likes/comments, other Claude surfaces>

## Suggested clean-up (nothing done yet)
- <e.g. withdraw invitations older than 3 months: list>
- <e.g. delete stray draft: title>
```

Rules:
- Relative dates are LinkedIn's rounded labels: say "approx.".
- Do not list people who are not part of the audit question. If the user did not ask for names, give counts only.
- Never include the user's credentials, tokens or private message bodies beyond a short preview.
